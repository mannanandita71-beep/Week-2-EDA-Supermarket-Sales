# Week-2-EDA-Supermarket-Sales
Exploratory Data Analysis and Visualization of a Supermarket Sales dataset using Python, Pandas, Matplotlib, and Seaborn.
# Week 2 - Exploratory Data Analysis and Visualization

## Project Overview

This project presents an Exploratory Data Analysis (EDA) of the Supermarket Sales dataset using Python.

## Objective

The objective of this project is to analyze sales data, identify important patterns and trends, and generate meaningful business insights through data visualization.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The Supermarket Sales dataset contains 1000 transaction records with information about customers, product lines, sales, payment methods, ratings, and other transaction-related features.

## Analysis Performed

- Data loading and inspection
- Missing value analysis
- Duplicate record checking
- Descriptive statistics
- Product line analysis
- City-wise sales analysis
- Customer type analysis
- Payment method analysis
- Correlation analysis
- Outlier detection
- Data aggregation
- Sales trend analysis
- Data visualization

## Key Findings

- Food and beverages recorded the highest total sales among product lines.
- Naypyitaw recorded the highest total sales among the cities.
- Member customers generated higher total sales than Normal customers.
- Cash recorded the highest total sales among payment methods.
- 9 potential outliers were identified using the IQR method.
